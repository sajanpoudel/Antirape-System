# Hardware

## Watch
- Arduino Nano
- 433 MHz transmitter
- GSM module and GPS module
- Push button that triggers the alert

## Server box
- Arduino Mega
- 433 MHz receiver (RadioHead `RH_ASK`)
- SIM900A GSM module on pins 12 (receive) and 13 (transmit)
- 16x2 LCD on pins 9, 8, 5, 4, 3 and 2
- Alert light or buzzer driver on pin 6
- Mains or battery power

The watch and the server box have to be within about 1 km of each other.
